# Inline home cue — 28 November 2026

The owner rejected a second Home-label row because it competed with the artist's name, and approved a small outlined house icon immediately before the name on its existing row. The icon stays visible on the homepage and subpages, preserving a consistent identity position.

The entire icon, English name and Chinese name remain one ordinary home link with the accessible name “Keng Seng Choo home” and a minimum 44px height. The 16px SVG icon uses the secondary text colour so the name remains prominent. English wordmark styling uses the explicit `wordmark-en` class rather than a first-child selector, preserving its size and weight after adding the icon.

The owner explicitly rejected a hover-based cue, since the main need is discovery on iPhones and iPads. There is no tooltip, hover-only Home text, native title hint or additional label row. The existing keyboard focus outline remains. Home navigation does not depend on JavaScript.

The production build and general, SEO and reference validators passed. Browser checks passed for home, artist and collections pages at 320, 390, 768, 1024 and 1440px in light/dark themes (30 combinations). Phone/tablet widths used touch emulation; actual iOS hardware was not tested. Checks confirmed the permanent icon, single-row alignment, no overflow, visible section links, no tooltip/title, successful touch/click navigation home and JavaScript-disabled home navigation. Desktop and phone headers were visually reviewed.
